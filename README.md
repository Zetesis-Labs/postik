# postiz-go

Programador de publicaciones en redes sociales: un binario en Go con Postgres y un frontend en TanStack.

Está inspirado en el comportamiento de [Postiz](https://github.com/gitroomhq/postiz-app), pero no comparte código ni historia con él. El fork que usamos como referencia es [`Zetesis-Labs/postiz-app`](https://github.com/Zetesis-Labs/postiz-app).
